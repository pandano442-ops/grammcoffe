# ГРАММ — сайт спешелті-кав'ярні

Готовий проєкт: `index.html`, `style.css`, `script.js`, `images/`.
Звичайний HTML + CSS + JS, без React/Node/баз даних/серверів — відкривається
прямо в браузері або через Live Server у VS Code.

## 📧 Підключення реальної відправки заявок на пошту (необов'язково)

Зараз форма бронювання працює повністю на клієнті: перевіряє поля і
показує гостю повідомлення "заявку надіслано" — без сервера, як і
просилося. Але сама заявка нікуди не надсилається, доки ви не підключите
щось на кшталт EmailJS (безкоштовно, без бекенду, без npm):

1. Зареєструйтесь на https://www.emailjs.com
2. **Email Services → Add New Service** → підключіть свою пошту → отримаєте `SERVICE_ID`.
3. **Email Templates → Create Template** з полями `{{name}}`, `{{phone}}`, `{{date}}`, `{{time}}`, `{{guests}}`, `{{message}}` → отримаєте `TEMPLATE_ID`.
4. **Account → General** → скопіюйте `Public Key`.
5. У `index.html` перед `<script src="script.js">` додайте:
   ```html
   <script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@4/dist/email.min.js"></script>
   <script>emailjs.init({ publicKey: "ВАШ_PUBLIC_KEY" });</script>
   ```
6. У `script.js`, у функції `initContactForm`, замініть блок `setTimeout(...)`
   на виклик:
   ```js
   emailjs.sendForm("SERVICE_ID", "TEMPLATE_ID", form).then(() => {
     status.textContent = `Дякуємо, ${nameField.value.trim()}! Заявку надіслано.`;
     status.classList.add("is-success");
     submitBtn.disabled = false;
     submitBtn.textContent = originalText;
     form.reset();
     initMinDateForBooking();
   });
   ```

## 📍 Google Карти

Зараз вставлена реальна робоча карта Google Maps за прикладовою адресою
(Хрещатик, 15, Київ). Щоб підключити справжню адресу кав'ярні:
1. Відкрийте Google Maps → знайдіть адресу.
2. «Поділитися» → «Вставити карту» → скопіюйте `src` з `<iframe>`.
3. Вставте його в `.contacts__map iframe` у `index.html`.

## 🚀 Швидкий старт для новачка

1. **Розпакуйте** ZIP-архів у будь-яку папку на комп'ютері.
2. Відкрийте **VS Code** → `File → Open Folder...` → виберіть розпаковану папку `gramm`.
3. Встановіть розширення **Live Server** (якщо ще не встановлене): іконка
   квадратиків зліва → пошук "Live Server" → Install.
4. Клацніть правою кнопкою на `index.html` → **"Open with Live Server"**.
5. Сайт відкриється в браузері за адресою на кшталт `http://127.0.0.1:5500` — готово!

(Можна й просто двічі клацнути на `index.html` — сайт відкриється у
браузері напряму, без Live Server, і теж працюватиме.)
